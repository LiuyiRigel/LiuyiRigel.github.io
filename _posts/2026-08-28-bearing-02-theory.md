本系列第 2 篇。要理解"为什么跨工况泛化难"，必须先理解**轴承故障信号的物理规律**与**数学表示工具**。本文从物理出发推导"故障阶次"这一跨工况不变量，再引入同步挤压变换（SSST）作为分析工具，最后给出我们提出的**通道化软阶次对齐（Channelized Fault-Order Priors）**理论框架。

---

## 1. 物理基础：轴承故障信号的产生机制

### 1.1 冲击串模型

滚动轴承的局部损伤（点蚀、剥落、裂纹）在与滚动体接触时产生**周期性冲击**。设轴的转频为 $f_r$，则不同损伤位置的冲击重复频率为：

$$f_{BPFO} = \frac{n}{2} f_r \left(1 - \frac{d}{D}\cos\alpha\right)$$

$$f_{BPFI} = \frac{n}{2} f_r \left(1 + \frac{d}{D}\cos\alpha\right)$$

$$f_{BSF} = \frac{D}{2d} f_r \left(1 - \left(\frac{d}{D}\cos\alpha\right)^2\right)$$

其中 $n$ 为滚动体数，$d$ 为滚动体直径，$D$ 为节圆直径，$\alpha$ 为接触角。

**关键观察**：这些特征频率与转频 $f_r$ 成正比。定义**故障特征阶次（Fault Characteristic Order, FCO）**为比值：

$$\text{FCO} = f_{fault} / f_r$$

则 FCO **只取决于轴承几何参数**，与转速无关。这是全篇最重要的物理不变量。

### 1.2 为什么跨转速会让模型失效？

假设模型在 1500 rpm（$f_r = 25$ Hz）下训练，学到"BPFO 频率 ≈ 107.9 Hz"这一绝对频率模式。当部署到 900 rpm（$f_r = 15$ Hz）时，BPFO 变为 ≈ 64.7 Hz——**绝对频率变了**，但阶次（BPFO/FCO ≈ 4.31）没变。

- 以**绝对频率**为判别依据的模型（如直接吃原始波形的 CNN）：陌生转速下特征错位 → 系统性误判；
- 以**阶次**为判别依据的表示（如阶比重采样）：跨转速不变 → 理论上可迁移。

这就是"跨转速盲点"的物理根源，也是后续 Paderborn 实验中 raw1d 模型在单转速训练下把陌生转速损伤大量漏报的原因（见系列第 7 篇）。

## 2. 数学工具：时频表示与同步挤压

### 2.1 从 STFT 到 SSST

经典的短时傅里叶变换（STFT）在时频平面上铺开信号能量，但受**海森堡不确定性**限制——时间分辨率与频率分辨率不可兼得。

**同步挤压变换（Synchrosqueezing Transform, SSST）**在 STFT/CWT 的基础上做了一步"能量重排"：对每个时频点估计其瞬时频率，把能量沿频率轴**挤压**到瞬时频率所在位置，从而锐化时频脊线：

$$T_s(\omega_l, b) = \sum_{a_k: |\omega(a_k, b) - \omega_l| \le \Delta\omega/2} W_s(a_k, b) a_k^{-3/2} \Delta a_k$$

其中 $W_s(a, b)$ 为 CWT 系数，$\omega(a, b)$ 为局部瞬时频率估计。

*SSST 与 STFT 的对比：同步挤压把冲击串的能量压缩到更窄的频带，故障特征线更清晰。*

### 2.2 SSST 的物理意义

对轴承冲击串信号，SSST 有三个对故障诊断至关重要的性质：

1. **瞬时频率估计**：冲击重复频率对应时频脊线，SSST 能把能量集中到该脊线；
2. **模态分离**：BPFO 及其谐波、共振频带在时频平面上可分离；
3. **稀疏性**：挤压后能量集中度更高，对噪声更鲁棒。

我们在自检中验证了实现正确性：纯音 100 kHz 自检挤压峰值落点误差约 1.4%（一个 FFT 箱内）；合成轴承 AE 信号（BPFO = 107.2 Hz 冲击串 + 125 kHz 谐振）的 SSST 估计冲击重复率 107.8 Hz、谱峰 124 kHz，均与真值一致。

## 3. 软阶次对齐理论：从"硬对齐"到"软对齐"

### 3.1 朴素方案：硬阶次对齐（阶比重采样）

既然 FCO 是跨工况不变量，最直接的想法是**阶比重采样**（order tracking）：把时域信号按转频等分角重采样，将绝对频率谱变成阶次谱。这样训练/测试都工作在阶次域，跨转速表示一致。

但实验给出了**反面证据**（变速振动 E3 实验，见系列第 5 篇）：

> 硬对齐（阶比重采样）把模型在绝对频域上的判别能力破坏了：soft（软）92.5% > base（原始）90.9% > hard（硬对齐）77.2%。

**原因**：阶比重采样是非线性重采样，会扭曲冲击的时域形态与幅值调制结构，损失了承载故障信息的绝对频率细节（如共振频带位置）。"跨工况不变"不等于"信息无损"。

### 3.2 我们的方案：通道化软阶次对齐

**核心思想**：不强制把表示变成阶次域，而是在网络内部**注入"阶次先验"作为辅助通道**，让网络自己决定如何使用。

具体地，对故障特征阶次 $\{FCO_1, FCO_2, \dots\}$（BPFO/BPFI/BSF/FTF 及其谐波），构建**物理先验通道**：

$$P_k(f, t) = g\left(\frac{f}{f_r(t)} - FCO_k\right)$$

其中 $g(\cdot)$ 是以 $FCO_k$ 为中心、带宽可调的窗函数，$f_r(t)$ 是（估计的）瞬时转频。这些通道与原始时频图**按通道拼接**（channelized），网络可以学习"在阶次先验的引导下"聚焦对应时频区域。

**"软"的含义**：先验是**提示（hint）而非约束（constraint）**——网络可以忽略、放大或组合这些通道，而不是像阶比重采样那样强制数据变换。

### 3.3 理论定位

我们把这个框架总结为"**相位格通道化软阶次对齐**"（报告 09 的理论章节草稿）：

| 层次 | 内容 |
|---|---|
| 物理层 | 故障冲击串 → 特征阶次 FCO（跨工况不变量） |
| 数学层 | SSST 锐化时频表示，瞬时频率估计 |
| 对齐层 | 软对齐：阶次先验通道注入，而非硬性数据变换 |
| 学习层 | 通道拼接 + 网络自适应权重 |

## 4. 跨工况泛化的难度阶梯（实证）

为了验证"什么因素决定跨域难度"，我们在多数据集上测量了不同偏移类型的难度阶梯（报告 07/19）：

| 偏移类型 | 典型精度 | 难度解释 |
|---|---|---|
| IID（同域随机划分） | 96.7–100% | 无偏移 |
| 换设备个体（同型号） | ~84% | 个体差异（安装/磨合/传感器） |
| 换工况（同设备） | ~83% | 工况改变绝对频率 |
| 换几何类型（跨轴承型号） | ~40% | 物理参数（FCO 等）都变了 |

这个阶梯说明：**偏移越接近物理本质（几何/工况），难度越高**——因为不变的物理不变量越少。它也为论文的"难度分析"提供了素材：泛化不是单点问题，而是一个难度谱。

---

## 5. 对后续实验的指导意义

这套物理-数学框架直接决定了后续所有实验的设计：

1. **表示选择**：为什么对比 raw/STFT/SSST/env/ord——它们对"阶次不变量"的保留程度不同；
2. **协议设计**：为什么 Paderborn 主线用"单转速 vs 多转速"——直接检验"覆盖目标工况"这一修复手段；
3. **结果解释**：为什么 env/ord 会在跨设备时出现"精度假象"（高 Acc 低 AUC 高 FPR）——解调表示丢掉了载波/共振信息，只剩"有没有冲击"这种对设备不鲁棒的判别（详见第 7 篇）。

---

## 6. 小结

- 轴承故障信号的**故障特征阶次 FCO 是跨工况不变量**，这是整个研究的物理基石；
- **SSST** 是保留阶次信息同时锐化时频表示的数学工具；
- **硬对齐（阶比重采样）会损失判别信息**，实测反而更差；
- 我们提出的**通道化软阶次对齐**把物理先验作为可学习的提示通道注入网络，是主线实验的"理论配菜"；
- 跨域难度遵循"**物理不变量越少越难**"的阶梯，为论文提供了难度谱叙事。
